# 퀴즈 & 점프 런너 (Quiz & Jump Runner)

2026 충북 AI 페스티벌 체험 부스용 웹앱입니다. 초등학생이 만든 달리기 퀴즈 게임을 업그레이드했습니다.

- `index.html`: 업그레이드한 앱
  - 1~4명이 칸을 나눠 동시에 달리기 (1인은 AI 3명과 대결)
  - 점프로 장애물 넘기, 퀴즈를 맞히면 부스트·틀리면 감속 (원작 규칙 그대로)
  - 내 칸에 보기가 바로 나오는 버튼, 상식 퀴즈 45문제, 퀴즈가 끝나면 정답 표시
  - 연속 정답 부스트, 동물 선수와 이름, 완주 시간 기록
  - 1인 도전 기록은 오늘의 랭킹에 올라감
- `board.js`: 부스 공용 랭킹 (Firebase Firestore, 컬렉션 `runner`). 다른 부스 앱과 같은 파일입니다.
- `원본_학생작품.html`: 학생이 만든 원본

조작: 1P `W`(1인은 Space도)·`1 2 3` / 2P `T`·`F G H` / 3P `I`·`J K L` / 4P `↑`·`← ↓ →`. 화면의 칸별 버튼으로도 됩니다.
